# gstack Agentic Rules & Ethos

Adhere to these rules when planning, designing, or implementing features in this repository.

## 1. YC Office Hours (Scope Control)
* Focus on shipping the narrowest possible product wedge that solves the user's problem.
* Push back on over-engineered specifications. Prioritize local hotseat play, fast onboarding, and high-readability interfaces over complex remote matchmaking or generic feature creep.

## 2. Confusion Protocol (Anti-Guessing)
* If there is an architectural ambiguity or lack of clarity regarding a traditional rule (e.g., team-mode capture coordinates), DO NOT guess. Stop and ask the user for clarification.

## 3. Premium Design (No AI Slop)
* Avoid generic material buttons, plain borders, and flat primary colors.
* Build bespoke, visually striking components (e.g., custom silk board rendering, bell-shaped lathe pawns, and smooth linear gradients). Every screen must feel premium and state-of-the-art.

## 4. Systematic Debugging
* Do not apply fixes without investigating. Trace the data flow, test hypotheses, and verify that the proposed solution does not break adjacent components.
